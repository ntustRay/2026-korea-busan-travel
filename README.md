# 2026 Busan Travel

## 手機旅行網站

本專案會將既有 Markdown 行程與注意事項建置成離線可用的手機 PWA，並由 GitHub Actions 發布至 GitHub Pages。

```bash
npm install
npm run start
npm run check
npm run test:e2e
```

- 正常與雨備行程仍以 Markdown 為唯一內容來源。
- 推送至 `main` 後，所有檢查通過才會更新 GitHub Pages。
- GitHub Pages 網址：<https://ntustray.github.io/2026-korea-busan-travel/>

## 旅遊風格與規劃原則

- **核心風格**：無腦放鬆
- **交通方式**：大眾交通優先，以地鐵、火車與輕軌為主
- **移動原則**：避免長距離移動、頻繁轉乘與跨區折返
- **行程密度**：每天安排少量重點景點，保留休息與彈性時間
- **住宿原則**：三晚住同一間飯店，不更換住宿
- **天候原則**：Day 2、Day 3 可依逐時天氣整天互換，不在現場長時間等雨停
- **用餐原則**：不預排餐廳，依當下區域與狀態現場決定
- **同行原則**：兩人全程一起行動，不安排分頭行程
